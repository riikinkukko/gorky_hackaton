# Слепой тест 26–27.10.2026 — протокол

Цель — проверить на людях, которые не видели ни кода, ни эталона, насколько ассистент понимает свободную речь. Участник получает **ситуацию** и добивается результата своими словами. Названий команд («поставь», «перенеси», «удали»…) в карточках нет.

| Файл | Для кого | Что |
|---|---|---|
| `cards.md` | участник | 10 карточек: по 2 на каждую из 5 задач ТЗ |
| `host_sheet.md` | ведущий | инструкция (молчать, не подсказывать), критерий «получилось» для пн и вт, таблица «задание → сказал → получилось → секунд» |
| `seed_user3.csv` | сервер | 12 записей пользователя 3: 6 прошлых (для «найти старое») и 6 будущих (для «узнать планы» и «исправить») |
| `reset_user3.sh` | сервер | сброс пользователя 3 к этим данным перед **каждым** участником; демо-данные пользователя 1 не трогает |
| `results_template.csv` | ведущий | шаблон для переноса таблиц |
| `summarize.py` | чат 7 | сводка: доля ✓, ✓ с первой фразы, медианы секунд и попыток по задачам ТЗ, карточкам и устройствам |

**Задачи ТЗ и карточки.** Записать задачу или напоминание — 1, 6. Записать встречу — 4, 9. Узнать планы — 2, 7. Найти старое — 3, 8. Исправить или отменить — 5, 10. Порядок перемешан, но «узнать планы на завтра» (2) идёт раньше переноса мастера (5), чтобы ответ не зависел от успеха участника.

**Пользователь и логи.** На тесте используется только пользователь 3, со своими данными, отдельно от демо-пользователя 1 с CSV. Реплики сами уходят в `riikinkukko/gorky_logs` (`turns/ГГГГ-ММ-ДД.log`). Ведущий записывает время сброса и начала каждого участника, чтобы потом отделить его реплики.

**Порядок на каждого участника (~15 минут):**
1. Сброс: `bash qa/blind/reset_user3.sh`.
2. Вход пользователем 3 на устройстве участника.
3. Вступительная фраза из листа ведущего.
4. Карточки 1–10, секундомер до 90 с на каждую.
5. Таблица.

**Участники.** 3–5 человек, не из команды, разные устройства: iPhone, Android, ноутбук. Хотя бы один — в шуме. Предупредить, что текст реплик сохраняется в логе. Личных данных не просить.

**Слепота теста.** Карточки и ожидаемые ответы лежат только в этой папке. Не пересылайте их чатам 1–3 и не правьте код под эти ситуации до конца теста: тест измеряет понимание незнакомых формулировок. Общие ошибки, найденные при подготовке (см. `qa/REPORT.md`, раздел «Слепой тест»), чинить можно: они не привязаны к карточкам.

**Итог.** Сводка — `qa/blind/results/SUMMARY.md`. Цифры для README и жюри: доля ✓ и «✓ с первой фразы» по пяти задачам ТЗ.
