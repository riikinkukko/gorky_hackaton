# Сессии — разговоры целиком

Каверзные реплики (`qa/adversarial/`) почти все однофразовые, а люди разговаривают сессиями. Здесь — разговоры по 3–40 реплик; прогон `backend/eval/run_sessions.py` проверяет **каждую** реплику (ожидания + оракулы + «тупики» вроде «Не нашёл запись «да»») и **нажимает каждую кнопку-подсказку**.

```bash
make sessions                                   # все файлы
cd backend && python -m eval.run_sessions ../qa/sessions/demo.jsonl --strict
```

| Файл | Что внутри | Кто пополняет |
|---|---|---|
| `demo.jsonl` | сценарий демо (`demo-main` — блокирует слияние в CI) и известные провалы демо (`known`) | чат 0, чат 6 |
| `long.jsonl` | длинные реалистичные разговоры и живые сессии со стенда целиком | чат 9, чат 7 |

Формат — в docstring `backend/eval/run_sessions.py`. `known` — известный провал: не блокирует `--strict`, а когда сессия начнёт проходить, прогон потребует снять пометку.
