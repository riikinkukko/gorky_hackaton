# Проверка обрезки начала на телефонах — «Удали эту задачу» × 10

Цель: после `web/v3` (pre-roll и post-roll по 400 мс) на стенде https://voice.planimetrika.online посчитать, в скольких попытках из 10 первая буква на месте. До `web/v3` на живом тесте было: «Удали» → «Дали», «Перенеси» → «Неси».

Нужно: iPhone (Safari) и Android (Chrome), по одному человеку на устройство, около 10 минут. Стенд общий с «Планиметрикой», поэтому темп обычный, без спешки.

## Подготовка (1 минута на устройство)

1. Открыть сайт и войти демо-пользователем: **iPhone — пользователь 2, Android — пользователь 3**. По номеру пользователя скрипт разделит устройства в логе.
2. Голосом или текстом: «Поставь задачу купить хлеб завтра в 10». Теперь у «эту задачу» есть цель.
3. Записать время начала по часам телефона.

## Серия А — подряд (10 попыток)

1. Зажать кнопку и **сразу**, без паузы, сказать «Удали эту задачу». Отпустить сразу после последнего слога.
2. На вопрос «Удалить задачу «Купить хлеб»?» ответить **«Нет»** (кнопкой или голосом), чтобы задача осталась для следующей попытки.
3. Посмотреть пузырь своей реплики и отметить, начинается ли он с «Удали». Если ассистент что-то **сделал** без вопроса (удалил, отметил выполненной), записать номер попытки — это главная ошибка.
4. Повторить 10 раз, между попытками не больше 10 с.

## Серия Б — после паузы (5 попыток, обязательно на iPhone, на Android по желанию)

Перед каждой попыткой ждать **30 с**, не трогая экран. Затем, как в серии А, сразу сказать «Удали эту задачу» и ответить «Нет».

Это слабое место по оценке чата 5. iPhone закрывает микрофон через 15 с простоя, и первая фраза после паузы может потерять начало, если говорить сразу. Отдельно отметьте, появлялась ли надпись «Говорите…» до того, как вы начали говорить.

## Разбор (на сервере, затем здесь)

```bash
cd /opt/gorky_code && docker compose -f docker-compose.yml -f docker-compose.shared.yml logs api --since 2h | grep "turn " > turns.txt
```

Файл `turns.txt` передать в чат 7. Разбор у себя:

```bash
python qa/tools/onset_report.py turns.txt          # iPhone = 2, Android = 3; пауза ≥ 25 с — «холодная»
```

На выходе таблица «устройство × серия: первая буква на месте / ничего не выполнено молча» и список всех реплик. Результат пойдёт в `qa/REPORT.md` и в сводку для чата 0.

**Готово, если:** в серии А ≥ 9 из 10 на каждом устройстве; во всех сериях — ни одного действия без подтверждения. Серия Б на iPhone со словами «сразу после нажатия» может дать меньше. Тогда это честная цифра для жюри и задача чату 5 (держать поток дольше или подсказка «подождите «Говорите…»»).

Если что-то пошло не так, в консоли браузера включается отладка микрофона: `localStorage.setItem("pomnyu.micdebug","1")`, строки `[mic]`. На Android консоль открывается через chrome://inspect, на iPhone — через Safari → Разработка.
