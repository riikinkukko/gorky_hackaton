# Промпт для чата 3 (данные) — имена вне списка организаторов при импорте

```
От чата 7 (QA), 24.10. Низкий приоритет: на демо не влияет, на голосовые записи тоже.

Что: storage/text.py PERSON_FORMS — закрытый список из 10 имён CSV организаторов. При импорте CSV
запись «Встреча с Ксенией по отчётности» получает person=[] и person_norm=[] (проверено на PostgreSQL),
и поиск «Когда я встречался с Ксенией?» её не находит: «Не нашёл встреч с Ксенией». Голосом созданные
записи с любыми именами («Тимур», «Вероника») находятся — там имя приходит из слотов NLU.
Воспроизведение: CSV из одной строки «1,2026-10-20,15:30,Встреча с Ксенией по отчётности» →
python -m app.cli import-csv f.csv --user 3 → SELECT person, person_norm FROM items WHERE user_id = 3;
→ [] []. Затем /api/chat «Когда я в последний раз встречался с Ксенией?» от пользователя 3 → «не нашёл».
Предложение: в enrich после словаря — pymorphy3 по тегу Name (или Surn) для слов с заглавной буквы
после «с/для/к» и в дательном/творительном падеже; нормальная форма → person_norm.
Починено: импорт такой строки даёт person=["Ксения"], поиск находит запись 20.10 15:30; 10 имён
организаторов и eval-real без изменений.
```
